# UX-006: Mobile Responsiveness and Accessibility

Status: Specified; no compliance claim.

## Scope and ownership

Incremental UX delivery workstream. Canonical business/security requirements remain in PRD-01 FOUND-FR-008; PRD-06/19/23/25; ARCH-09. This PRD adds implementation and acceptance detail; it does not replace or close those tickets. No new database schema, API contract, tenant permission or parallel frontend framework is authorized by this PRD.

## Dependencies

UX-001/003/005 patterns. PRD-23 owns WCAG 2.2 AA and keyboard equivalence; this PRD organizes remediation and evidence.

## User journeys

Phone user completes a Card action without page overflow; keyboard user moves a Card without dragging; zoom/screen-reader user follows dialogs, errors and realtime updates.

## Implementation tasks

- [ ] UX-006-T-01: Inventory actual screens at 320/390/768/1280px and 200% text zoom / equivalent 400% reflow; prioritize operational MVP blockers.
- [ ] UX-006-T-02: Repair wrapping/overflow and touch targets incrementally; retain intentional local Kanban scrolling.
- [ ] UX-006-T-03: Audit landmarks/headings/labels, visible focus, contrast, keyboard drag alternatives and bounded live announcements.
- [ ] UX-006-T-04: Record automated results and manual assistive-technology/physical-device review separately.

## Acceptance criteria

- UX-006-AC-01: Critical MVP workflows remain available at every supported width without page-level horizontal scroll, clipped controls or lost data.
- UX-006-AC-02: WCAG 2.2 AA checks cover keyboard, focus visibility/not obscured, names, contrast and minimum target sizing under PRD-23.
- UX-006-AC-03: Pointer operations have keyboard equivalents; dialogs and realtime events maintain predictable focus and announcements.
- UX-006-AC-04: Axe pass is necessary evidence, not full accessibility acceptance; manual review and exceptions are recorded.

## Automated tests

- UX-006-TC-01: Unit: state semantics, focus and keyboard alternatives for changed components.
- UX-006-TC-02: Playwright: viewport fit, text zoom/reflow, touch and keyboard complete workflows with Axe at four widths.
- UX-006-TC-03: Regression: existing Kanban keyboard/touch, lifecycle/recovery and Portal tests; human screen-reader and physical-device acceptance logged separately.
