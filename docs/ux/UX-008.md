## Acceptance criteria

- UX-008-AC-01: Every PRD change passes TypeScript, lint, unit, relevant integration, affected Playwright, role, responsive, accessibility and existing regression gates before merge.
- UX-008-AC-02: Shared shell/token changes trigger all affected consumers and required full release regression; targeted development tests do not replace that gate.
- UX-008-AC-03: Visual diffs require explicit review; changes cannot be approved by silently regenerating baselines, skipping tests or relaxing assertions.
- UX-008-AC-04: A failure is recorded with scope/cause/impact/owner/disposition and rerun evidence; unknown or blocked checks cannot count as passed or accepted.

- UX-008-TC-01: Source/CI guards: verify-browser-shards.mjs and verify-integration-suites.mjs plus relevant contract tests.
- UX-008-TC-02: Playwright/Axe: controlled and real-service scenarios, role denials, responsive/reflow and approved screenshot fixtures.
- UX-008-TC-03: Negative checks: prove omitted required suite, changed baseline or swallowed failure cannot satisfy acceptance; current immutable release evidence remains required.
