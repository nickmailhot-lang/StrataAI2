## User journeys

Internal member opens a stable Board/Card deep link, identifies context, opens navigation on a phone, visits Notifications, then returns with browser Back. Keyboard user skips repeated navigation. Portal-only user cannot mount internal navigation.

## Acceptance criteria

- UX-001-AC-01: Existing Board/Card deep links and browser Back preserve context; no API, schema, tenant or original-command recovery behavior changes.
- UX-001-AC-02: At widths below 600px, keyboard/touch users can open/close the shared drawer, choose Organizations/Work/Notifications and return focus after dismissal. Unimplemented modules remain absent from daily navigation; no new routes.
- UX-001-AC-03: Skip to main content focuses the single main landmark; enabled current section exposes aria-current; controls have names and visible focus.
- UX-001-AC-04: At 320/390/768/1280px and text zoom, shell controls fit without page overflow; intentional Board canvas scrolling stays local.
- UX-001-AC-05: Internal menu unmounts on definitive access withdrawal; independent public Board and terminal recovery exceptions keep their own authorization. Portal navigation remains separate.
