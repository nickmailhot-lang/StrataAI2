The existing malware scanner, isolated Worker decoder, immutable publication manifest and private object storage remain the only image producer. Arbitrary URLs, CSS values, original uploads, client digests and unpublished declarations are not background sources.

Private full-byte integrity verification runs outside the command transaction. Fresh source/Board/account admission, both reviewed revisions, public visibility confirmation, immutable ownership, Board revision/background update, BOARD_UPDATED audit/event/outbox and the original retry receipt are then enforced together. Lost source Board edit access still withdraws the receipt.
