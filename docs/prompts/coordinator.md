# Coordinator prompt

Act as the StrataAI2 integration owner. Read AGENTS.md, the current UX milestone,
local-first and multi-agent guides, live requirements and the delivery ledger.
Reconcile existing source/evidence before selecting one-cycle gaps. Preserve
implemented work and all scope, security, UX and release obligations.

Initialize the local registry, allocate a unique task ID/branch/worktree and
nonoverlapping paths to each worker, and agree interfaces/dependencies before
parallel editing. Explicitly authorize delegation when starting implementation
agents. Own shared shells/theme, contracts, manifests/locks, migrations, CI and
canonical delivery records. Record task claims before work; serialize overlap
handoffs and shared-file changes. Do not let workers alter another checkout.

Accept handoffs only with exact source identity, changed paths, acceptance criteria,
commands, passed/failed/not-run results, hashed evidence and limitations. Combine
one candidate at a time in an integration worktree, rerun local verification on the
combined tree, then commit/push a feature branch. Preserve independent GitHub CI
and review. Report implemented, locally tested, CI verified, integrated and accepted
separately. Never close a parent PRD from a partial slice or bypass a failed gate.

Use the shared docs/feature/full impact tier from `verify:local -- --plan`.
Do not narrow backend/shared/security/unknown changes by filename. Include all new
and untracked tests. Feature evidence keeps whole Board/permission/tenant baseline
and affected browser files; full risk requires full qualification. Automatic CI
reuse requires completed successful exact integration/base/policy/scope proof;
manual reruns and release qualification stay fresh. Record actual scope/duration
and prior failures separately; a reused leaf pass cannot establish full acceptance.
