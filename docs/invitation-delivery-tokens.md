# Reconstructable invitation delivery proof

`IInvitationDeliveryTokenSigner` provides API/Worker reconstruction from the actual Organization ID, invitation ID and key version. The existing validated runtime mail key ring supplies this dedicated interface when production email is enabled. It does not extend the global verification/reset-purpose enum or change their existing derivation bytes.

Invitation proof uses HMAC-SHA256 with the separate `strataai:invitation-delivery:v1` context and both UUIDs. The result is a 43-character URL-safe bearer. Different Organizations, invitations, key aliases or identity purposes cannot interchange proof. Restart and current-key rotation reproduce a queued invitation's original proof while its original key remains in the ring. Missing versions, empty identities and disposed key material fail closed. Shared interface registrations point to the same signer; idempotent disposal clears the underlying keys safely.
